# Scheduled playback timing on macOS

`start()` execution time is not stimulus timing precision. On a prepared stream,
it mostly checks whether the engine is already running. Use the timing probe to
measure scheduling and native queue submission separately.

## What is measured

`examples/measure_timing.py` exercises the patched `tachypy.Audio` scheduler with
one silent float32 sample per trial. It prepares the device once per condition
and buffer size, schedules each trial 20–60 ms into the future, and waits for
that sample's buffer to return before scheduling the next trial. Randomized
delays reduce phase locking to the callback period. Five initial trials are
discarded by default.

The private macOS native `_timing()` diagnostic records:

- When the sample is copied from the ring into an AudioQueue buffer.
- Times immediately before and after `AudioQueueEnqueueBuffer`.
- When the callback returns that buffer for reuse.
- A count of successfully enqueued buffers containing user samples.

All native timestamps use `mach_absolute_time`, converted to nanoseconds. The
probe checks that a native clock reading lies between two Python
`time.monotonic_ns()` readings. Each trial must increment the data-buffer count
exactly once. Silence generated by the idle engine does not increment it.

The Python wrapper timestamps entry and return from the trial's `write()` call.
The report separates:

- **Scheduling error:** write entry minus requested submission time.
- **Write duration:** API execution time, not scheduling precision.
- **Copy delay:** ring-to-AudioQueue copy time minus write entry.
- **Queue submission delay:** enqueue return minus requested submission time.
- **Enqueue duration:** the native API-call bracket.
- **Buffer return delay:** buffer callback time minus requested submission time.

Each metric includes mean, median, minimum, maximum, population standard
deviation, and interpolated p95/p99. Standard deviation describes observed
jitter; median delay describes systematic latency. Neither is a guarantee.

## Running it

Use an environment with NumPy and both patched packages. From the tachyaudio
checkout, build the extension and run:

```sh
python setup.py build_ext --inplace
PYTHONPATH=/path/to/patched/tachypy/src:src python examples/measure_timing.py \
    --trials 100 --block-sizes 128 480 1024 \
    --conditions idle python-thread --output build/timing-report.json
```

The command writes raw timestamps, source hashes, environment/settings, and
summaries to JSON, plus a neighboring Markdown report. Existing reports are
never overwritten. `--device-id` selects a specific output device.

`python-thread` runs a competing CPU-bound Python thread in the same process.
It tests GIL contention and is not a simulation of every GPU, CPU, driver, or
operating-system load. The probe leaves Python's thread switch interval alone
and records it in the report.

To verify native timestamp ordering and the report calculations:

```sh
python -m unittest discover -s tests
TACHYAUDIO_TEST_HARDWARE=1 python -m unittest discover -s tests
```

The first command skips device tests; the second requires a working output
device and performs silent playback. Native timestamp tests are macOS-only.

## Interpretation limits

Enqueuing data is not the same as rendering it. Previously queued silence and
device buffers can still delay output after the timestamp. Buffer return is
also not a first-sample presentation timestamp: the entire buffer, including
padding after the one sample, is involved. Do not subtract these measurements
from an experiment's requested onset and call the result calibrated sound onset.

Native instrumentation performs a few clock reads and counter updates per
data-bearing buffer, so results describe the instrumented build. The probe
does not measure cold-device startup, overlapping stimuli, or acoustic onset.
An independent electrical/acoustic loopback test remains necessary for
end-to-end stimulus timing. More trials, repeated sessions, and representative
experiment loads are needed before setting a supported timing tolerance.
